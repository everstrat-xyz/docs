## Sync Rules

- if contract roles or queue rules change, update [Risk & Trust](/risk-and-trust/roles-and-permissions) and [Developers / Protocol](/developers/protocol/high-level-architecture)
- if source changes before deployment, document the proposal separately from live behavior
- if keeper functions or parameters change, update automation and exit-delay descriptions
- if governance operations execute, refresh the dated deployment snapshot from chain state
- if frontend addresses change, update the canonical [Contract addresses](/reference/contract-addresses), the dated [deployment snapshot](/operations/current-deployments), and affected [Developers pages](/developers/contracts/overview)
- if subgraph entities or endpoint versions change, update [Developers / Data](/developers/data/subgraph-overview) and [Operations / Subgraph deployments](/operations/subgraph-deployments)
- if landing terminology changes, check homepage and introduction pages

## Common Drift Sources

- old README examples
- stale `.env.example` endpoints
- address changes made only in frontend config
