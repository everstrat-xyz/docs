## Portfolio

The app's **Portfolio** page (`/portfolio`) shows the connected wallet's position history,
current account state, available claim/cancel actions, and lifetime deposit/redemption totals.
The old `/dashboard` route redirects to Portfolio.

The position chart values EVE using the protocol's on-chain **redemption price**. It offers
Value and Return views in ETH or USD. It combines indexed wallet events with stored historical
redemption prices and direct current price reads.

Important calculation details:

- EVE escrowed for an unprocessed exit remains part of the wallet's position.
- Processing an exit removes that EVE and records the redeemed ETH; claiming transfers ETH
  already credited by processing.
- External EVE transfers, including exchange trades or gifts, are valued at the redemption
  price at the time. The protocol does not know their actual trade cost.
- At the snapshot's connector weight of 0.9, entry uses a higher premium price, so a new mint
  starts with redemption value below its deposit cost.
- Missing historical prices or stale/failed current reads can produce an unavailable state.
  Partial data is not presented as a zero return.

Portfolio returns are estimates under these valuation rules. They are not a complete wallet
cost-basis or tax calculation.

## Metrics

The **Metrics** page (`/metrics`) shows protocol NAV, supply, holder/activity aggregates,
liquidity, strategy allocation, stored performance history, and EVE market history.
The old `/stats` route redirects to Metrics.

| Data | Source | Meaning |
| --- | --- | --- |
| Current NAV, protocol prices, liquidity, supply | Ethereum contract reads | Current protocol state |
| Deposits, redemptions, users, requests | GoldSky subgraph | Indexed contract events |
| Historical returns and strategy series | Stored block-pinned snapshots | Sampled protocol history |
| EVE/WETH market chart | GeckoTerminal market data | External market price |

The market chart can differ from the AMM redemption and mint prices. It does not determine
protocol accounting. Snapshot returns measure the recorded period and are not annualized
or guaranteed future yield.

## Account state and activity

Portfolio uses direct RPC snapshots for balances, claimable ETH, queued requests,
and cancellation eligibility. Claim and Cancel are separate available actions.
The connected-wallet dialog shows wallet information and confirmed Activity history.

Activity history is indexed by GoldSky and may lag a confirmed receipt. Submitted transactions
have a separate local status while confirmations are pending. Use the explorer link to verify
a transaction when the indexer is behind.
