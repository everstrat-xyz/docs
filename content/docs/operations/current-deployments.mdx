| `AMM.freeBalance()` | `0` |

All ETH held by AMM was reserved for existing claims. Every new successful positive-size
exit at this block would therefore queue, subject to the queued minimum and other checks.
Deposits are forwarded to Controller, and `exitLiquidityTargetETH = 0` disables routine
AMM float top-up. The contracts still settle an exit immediately when free balance covers it,
and authorized liquidity transfers can raise free balance. Recheck it before assuming an
immediate exit is available. This snapshot does not establish historical exit counts.
