title: Environment variables
description: Runtime configuration across the docs app and the web3 app.
---

## Docs App

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | absolute site URL for metadata |

## Web3 App

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_APP_URL` | wallet metadata and public URL |

`NEXT_PUBLIC_APP_URL` falls back to `http://localhost:3000` when unset or blank.

The app's subgraph endpoint and WalletConnect project ID are currently configured in
`everstrat-xyz/app/src/config/index.ts`: `subgraphUrl` supplies `CONFIG.SUBGRAPH_URL`,
and `CONFIG.WALLETCONNECT_PROJECT_ID` holds the wallet connection project ID.
Changing either requires updating that source configuration and rebuilding the app.
`NEXT_PUBLIC_SUBGRAPH_URL` and `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` are not read by
the current app and do not override these values.

## Operational Rule

If these values change in production, update both runtime configuration and the docs that describe it.
