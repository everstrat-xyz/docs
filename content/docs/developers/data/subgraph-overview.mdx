See the [subgraph and RPC data-flow diagram](/developers/data/subgraph-and-data-access#everstrat-data-diagram) for how consumers read protocol data.

## What the subgraph exists to do

- index protocol events whether submitted through the app or another client
- track keeper-driven queue state transitions that happen after the user transaction
- serve account profile data and activity history to the frontend

## Mandatory indexed contracts

- `AMM`
- `ExitQueue`
- `EVE`
- `Whitelist`
- `Timelock`

The current schema also indexes token transfers, holder counts, protocol/daily flows,
whitelist access, and timelock operations. See [Entities](/developers/data/entities).

## Current deployment target

`https://api.goldsky.com/api/public/project_cm7aaq2gvh5ak01wf890nferb/subgraphs/everything-strategy-mainnet/prod/gn`
