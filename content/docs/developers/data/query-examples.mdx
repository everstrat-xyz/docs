## Latest activities

```graphql
query LatestActivities {
  userActivities(first: 20, orderBy: timestamp, orderDirection: desc) {
    id
    type
    status
    txHash
    ethAmount
    eveAmount
  }
}
```

## Latest redemption requests

```graphql
query LatestRequests {
  redemptionRequests(first: 20, orderBy: createdAt, orderDirection: desc) {
    id
    status
    tokensToBurn
    requestedEthEffective
    finalEvePrice
    isWithinTolerance
    viaEscapeHatch
  }
}
```
