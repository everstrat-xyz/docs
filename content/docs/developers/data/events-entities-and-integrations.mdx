## Event Families That Matter

- approvals and transfers on EVE
- mint, redemption, and claim events on AMM
- queue state events on ExitQueue
- whitelist access events and timelock operation events

## Entity Families That Matter

- `User`
- `UserActivity`
- `ExitBatch`
- `RedemptionRequest`

Additional transfer, metric, access, and governance entities are listed in [Entities](/developers/data/entities).
Processing credit and actual ETH claim are separate events; do not count both as payouts.

## Integration Advice

If you need current balances or real-time pricing, use direct RPC reads. If you need queue history or
user history, use the subgraph.
