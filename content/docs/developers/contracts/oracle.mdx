## Purpose

Oracle maintains token/USD feeds and optional token-pair feeds. Native ETH is represented by
`address(0)`. Token support is established by `updateUsdFeedInfo()`; there is no separate
add-token operation.

## Permissions

Feed registration, updates, token removal, pair-feed configuration, and UUPS upgrades require
**`ADMIN_ROLE` in Registry**. The protocol does not define an `ORACLE_MANAGER_ROLE`.

## Valuation and staleness

Conversion uses a direct pair feed when available, an inverse pair feed when available, or
the ratio of the two token/USD feeds. Non-positive or invalid feed answers and stale observations
can revert a required valuation.

Oracle supports the bootstrap USD minimum, USD display values, and the ETH valuation of
strategy paired tokens and supported ERC-20 balances held by StrategyManager. Since the AMM
prices from that NAV, oracle failures can also block ordinary minting, exits, and batch pricing.
