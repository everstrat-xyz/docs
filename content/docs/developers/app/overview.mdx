## Current routes

| Route | Purpose |
| --- | --- |
| `/mint` | Mint and burn form, approvals, slippage, and transaction status |
| `/portfolio` | Wallet position, returns, claimable ETH, requests, and history |
| `/metrics` | Protocol metrics, strategy allocation, and historical/market charts |

Legacy `/dashboard` and `/stats` routes redirect to Portfolio and Metrics.
App access remains invite-gated.

## Data and wallet behavior

The app supports Ethereum mainnet (chain ID **1**), wallet connection, and strict
unsupported-network handling. Direct RPC reads determine wallet balances, claimable ETH,
and actionable queued requests. Goldsky provides indexed activity and transfer history.

Portfolio uses historical redemption prices to value position movements.
Metrics combines on-chain reads, indexed history, sampled historical snapshots, and
GeckoTerminal market data rendered in a native chart. It is no longer documented as
an embedded GeckoTerminal iframe or a prototype dashboard.

A secondary-market quote is not AMM's protocol redemption price.
See [Tracking your position](/using-everstrat/tracking-your-position) for calculation
boundaries and missing-data behavior.
